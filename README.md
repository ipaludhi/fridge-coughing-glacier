One-line roast of a smart fridge: its ice maker sounds like it's coughing up a glacier every morning, then proudly delivers one cube.

## Run it

```sh
node main.ts
```

Writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
